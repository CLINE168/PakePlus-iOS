# 铁路工务智慧巡检系统（Web 版）

依据《铁路工务智慧巡检系统.doc》用户手册实现的单机 Web 版软件。
纯前端实现，使用浏览器 `localStorage` 保存数据，**无需安装、无需联网**。

## 运行方式
直接用浏览器（推荐 Chrome / Edge）打开本文件夹中的 **index.html** 即可。
（也可将整个 `铁路工务智慧巡检系统` 文件夹放到任意 Web 服务器目录下访问。）

## 功能模块（对照用户手册）
- **系统登录 / 系统界面**：左侧功能列表区 + 顶部功能操作区 + 中间信息显示区
- **基本情况**：养护站基本信息（保存修改/更换照片）、职工信息、管养路段、管养桥梁、管养涵洞、管养隧道、机械设备台账、库存材料（含低库存预警）
- **日常管理**：派工单（按日期查看、左右箭头切换、按类别筛选、新建/修改/删除、**复制到另一天**、**天气录入**、**导出 Excel(CSV)**）、临时用工、出工出勤情况统计（时间段查询 + 导出）、机械使用登记、材料使用登记
- **铁路技术状况**：技术状况调查（选线路/项目，填人员/时间/起止桩号，弹出评定表按每公里10段评分、自动算综合评分与等级）、技术状况明细表、技术状况汇总表（可导出）、实时铁路技术状况
- **巡查管理**：铁路巡查日志录入、巡查问题管理（登记上级发现的问题并跟踪处理状态）

## 说明
- 所有数据保存在浏览器本地，刷新后保留；如需恢复初始演示数据，可在浏览器开发者工具中清除本网站 `localStorage`。
- 技术状况等级：综合评分 ≥90 优、≥80 良、≥70 中、<70 差。
